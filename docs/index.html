かんたん見積・請求くん

サポート

対象は iPhone アプリ「かんたん見積・請求くん」（Bundle ID jp.mitsumori.app）です。最終更新: 2026年10月8日。

一人親方や小規模の工事業者のための、見積書・請求書アプリです。現場で品目と数量を選ぶだけで見積書を作り、1タップで請求書にして、PDF を LINE やメールで送れます。アカウントはありません。

使い方

  1. 「設定」→「自社情報」で、屋号または氏名・住所・電話・振込先を登録する。適格請求書発行事業者の登録番号（T＋13桁）は、登録している方だけ入れてください。
  2. 「取引先・品目」で宛先（会社は御中、個人は様）と、よく使う作業や材料（品目・単位・単価・税率）を登録する。
  3. 「書類」→「新規作成」で見積書を作り、「品目から追加」で数量を入れる。自由入力の行も足せます。
  4. 保存すると A4 縦の PDF が表示されます。「PDFを送る」から LINE・メール・ファイルなどに送れます。
  5. 受注したら「この見積書から請求書を作る」で請求書にし、入金を確認したら状態を「入金済」にします。未入金の請求書は「未入金」タブにまとまります。

消費税の計算（インボイス制度）

単価は税抜で入力します。消費税は 1 枚の書類ごとに、税率（10%・8%）ごとの合計額から 1 回だけ計算し、1 円未満は切り捨てます。書類には税率ごとの対象額と消費税額、軽減税率（8%）の品目の「※」印、登録番号（入力した場合）が印字されます。

無料とプレミアム

無料では取引先 2 件・品目 10 件まで登録でき、書類は月 3 件まで新しく作れます（見積書から請求書への変換は数えません）。PDF の送信、見積書から請求書への変換、未入金の管理は無料で使えます。無料プランの PDF には、下に小さく「かんたん見積・請求くんで作成」と入ります。

プレミアムは月額 ¥100、または年額 ¥1,200 の自動更新サブスクリプションです（はじめての方は1週間無料）。取引先・品目・書類が無制限になり、PDF の表示が消え、印影・ロゴの印字、過去の書類の表示と検索、CSV の書き出しが使えます。解約しても、作った書類は iPhone の中に残ります。広告はありません。

支払いや解約の条件は 利用規約 に書いてあります。購入の復元は、アプリの「設定」→「プラン」→「購入を復元」です。

データの扱い

書類・取引先・品目・自社情報は、この iPhone の中だけに保存します。運営のサーバーへは送りません。詳しくは プライバシーポリシー です。
